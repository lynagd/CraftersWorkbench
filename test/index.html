  • Glowing frame = the kernel, a small filter that slides over the image
  • Tiles inside it = the pixels under the kernel
  • Your tool = the weights (the colours). Each pixel is multiplied by its weight, then all the results are added up
  • Ringed tile = the output pixel, the one that changes
  • Whole pass = a convolution: the same kernel at every position makes a new image
